# Obsidian Vault

Personal knowledge base synced via [obsidian-git](https://github.com/denolehov/obsidian-git).  
Accessible from Claude Code on the web from any device.

## Structure

```
vault/
├── Daily Notes/     # 日次ノート（obsidian-git で自動同期）
├── Projects/        # プロジェクト別ノート
├── Areas/           # 継続的な関心領域
├── Resources/       # 参考資料・メモ
├── MOC/             # Map of Content（索引ノート）
├── Archive/         # アーカイブ
└── Templates/       # ノートテンプレート
```

## Sync Setup

obsidian-git プラグインで自動同期（15分ごとに auto commit & push）。

## Claude Code Access

このリポジトリは Claude Code on the web の GitHub MCP 経由でアクセス可能。  
どのデバイスのブラウザからでも、ノートの読み書き・検索が可能。
